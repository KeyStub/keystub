# KeyStub brand kit

The logo is a car key whose head is a ticket stub: the key is the car, the stub is the receipt for everything it costs.

## Which file to use

| Need | File |
|---|---|
| Instagram / Facebook / X / YouTube / TikTok profile picture | `3-social/keystub-profile-picture.png` (1080×1080, safe for circle crops) |
| X header | `3-social/keystub-x-header-1500x500.png` |
| Facebook cover | `3-social/keystub-facebook-cover-1640x624.png` |
| YouTube banner | `3-social/keystub-youtube-banner-2560x1440.png` |
| Google Workspace logo, email signature, documents (white/light background) | `4-logo/keystub-logo-navy-1000.png` |
| Logo on a dark photo or dark background | `4-logo/keystub-logo-white-2000.png` |
| App icon, favicon | `2-app-icon/keystub-icon-rounded-*.png` |
| Editing in Canva or a design tool | any `.svg` (text is already converted to shapes, so no fonts needed) |

`1-mark` = the key on its own. `4-logo` = key + "KeyStub" wordmark. Each file comes in SVG (scalable, editable) and PNG (ready to upload).

## Colours

| Name | Hex | RGB | Use for |
|---|---|---|---|
| KeyStub Navy | `#18263F` | 24, 38, 63 | Main brand colour: backgrounds, headers, logo on light backgrounds |
| Ticket Yellow | `#F4C430` | 244, 196, 48 | Accent: the ticket in the logo, buttons and highlights on navy. Don't put yellow text on white (too faint). |
| Paper | `#F2F4F7` | 242, 244, 247 | Light page backgrounds, the key blade |
| Ink | `#16202F` | 22, 32, 47 | Body text on light backgrounds |
| Slate | `#47546A` | 71, 84, 106 | Secondary text, captions |
| White | `#FFFFFF` | 255, 255, 255 | Text and logo on navy |

## Fonts (both free, Open Font License)

- **Archivo ExtraBold (800):** the logo wordmark and big headlines. [Google Fonts](https://fonts.google.com/specimen/Archivo)
- **IBM Plex Sans (Regular 400 / Medium 500 / SemiBold 600):** everything else: body text, buttons, captions. [Google Fonts](https://fonts.google.com/specimen/IBM+Plex+Sans)

In Canva, search the font menu for "Archivo" and "IBM Plex Sans".

## Rules

- Give the logo breathing room: at least the height of the key's ring hole on every side.
- Don't stretch, rotate, recolour (beyond the navy / white / colour versions) or add effects.
- On light backgrounds use the navy logo; on navy or dark backgrounds use the white/colour logo.
- Tagline: "Know what your car really costs."

Regenerate with `scratchpad/brandtool/build.js` (ask Claude) if anything changes.
